
## Open Modelica en distintos Sistemas Operativos o IDES
Si desea utilizar OpenModelica en un Entorno de desarollo integrado como lo es VsCode, puede realizarlo a traves de las siguientes extensiones.
Instalar utilizando las siguientes extensiones: 
- **Modelica** (de SimplyDanny)
- **ModelScript** (permite edición de diagramas y simulación)
- **Modelica Language Server** (Oficial de OpenModelica)
